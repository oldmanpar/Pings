# 🌟 Pings - シンプルなPing監視ツール

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 💡 概要

Pingsは、複数のネットワークホストの疎通性をリアルタイムで監視し、詳細な統計情報を記録するために開発された、**軽量かつ高機能なWindowsフォームアプリケーション**です。

ネットワークの基本的なヘルスチェックや、障害発生時の状況把握に役立ちます。

---

## 💻 主な機能

* **マルチホスト監視:** 複数のIPアドレスやドメインを同時に監視します。
* **リアルタイムステータス表示:** OK / Down / 復旧の状態を色で視覚的に識別できます。
* **ステータスボード:** 監視対象を1行チップとして縦優先で敷き詰め、多拠点（200拠点規模）の状態をスクロールなしで一望できます。チップのダブルクリックで監視統計の該当行へジャンプします。
* **詳細な統計:** 応答時間の平均/最小/最大、失敗回数、連続失敗時間などを記録します。オプションでジッタ①（最大値−最小値）、ジッタ②（パケットペア平均）、標準偏差の表示も可能です。
* **障害イベントログ:** Down開始時刻と復旧時刻、ダウン時間を正確に記録し、エクスポート可能です。Down前後の統計スナップショットも保存されます。
* **個別Pingターミナル:** 監視統計の行をダブルクリックすると、その拠点への個別Pingを実行しログを自動保存できます。
* **Traceroute:** 監視対象のうちチェックした拠点へ並列でTracerouteを実行し、結果を並べて比較・保存できます。
* **柔軟なファイル入出力:**
    * 監視対象リストの読み込みは、プログラム保存形式（CSV）に加え、**ExPing形式（スペース/タブ区切り）**のテキストファイルに対応しています。
    * 監視結果、障害ログのCSVファイル保存に対応しています。
* **操作方法ヘルプ:** メニュー「ヘルプ → 操作方法」から、基本操作・タブの説明・ジッタ①②・標準偏差の解説を参照できます。

## 🛠️ 利用方法 (実行ファイルを使用する場合)

1.  **リリースのダウンロード:**
    リポジトリの **[Releases](https://github.com/oldmanpar/Pings/releases)** ページから、最新バージョンの **`Pings_vX.XX.exe`** をダウンロードします。
2.  **実行:**
    ダウンロードした **`Pings_vX.XX.exe`** をダブルクリックして起動します。（展開不要・単体で動作）
